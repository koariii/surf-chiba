# surf-chiba — 千葉 波チェック

千葉県のサーフポイントの波・うねり・風の予報をまとめて確認できる、1ファイル完結のWebアプリです。
予報データは [Open-Meteo](https://open-meteo.com/) の無料APIから取得しています（APIキー不要）。

## 主な機能

- **3日間の予報**: 今日・明日・明後日を日付タブで切り替え
- **エリア絞り込み**: 全エリア / 千葉南 / 千葉北
- **おすすめ表示**: 総合評価（◎ ○ △ ×）の高い順にポイントを並べて表示
- **詳細画面**: ポイントをタップすると、時間ごとの波高・うねり・周期・風速・風向をグラフで確認できる

## 評価のしくみ

各ポイントに設定した「オフショア方向」をもとに、次の3項目を点数化して合計します。

| 項目 | ◎ (3点) | ○ (2点) | △ (1点) | × (0点) |
|---|---|---|---|---|
| 風向 | オフショア (±45°) | サイドオフ (±90°) | サイドオン (±135°) | オンショア |
| うねりの向き | 正面入射 | 斜め入射 | 端入射 | 当たらない |

- **波のサイズ**: 0.3〜2.0m なら2点、2.0m超なら1点、0.3m未満（フラット）なら0点
- **総合評価**: 合計7点以上 ◎ / 5点以上 ○ / 3点以上 △ / それ未満 ×

波高の目安は次のとおりです。

| 波高 | 表示 |
|---|---|
| 〜0.3m | フラット |
| 0.3〜0.6m | ヒザ〜モモ |
| 0.6〜1.0m | コシ〜ハラ |
| 1.0〜1.5m | ムネ〜カタ |
| 1.5〜2.0m | カタ〜アタマ |
| 2.0m〜 | アタマ以上 |

## 使い方

ビルドもインストールも不要です。`index.html` をブラウザで開くだけで動きます。

```sh
# ローカルサーバーで確認する場合（任意）
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

GitHub Pages などの静的ホスティングにそのまま置いて公開することもできます。

## 使用API

- 波・うねり: [Open-Meteo Marine API](https://open-meteo.com/en/docs/marine-weather-api)（`swell_wave_height`, `swell_wave_direction`, `swell_wave_period`, `wave_height`）
- 風: [Open-Meteo Forecast API](https://open-meteo.com/en/docs)（`wind_speed_10m`, `wind_direction_10m`、単位 m/s）

## ポイントの追加・編集

`index.html` 内の `POINTS` 配列に要素を追加・編集します。

```js
{ id:"example", name:"ポイント名", area:"千葉南", lat:35.000, lon:140.000, offshore:270, bottom:"サンド", note:"メモ" },
```

- `area`: `千葉南` または `千葉北`（エリアタブの絞り込みに使用）
- `offshore`: オフショアになる風が吹いてくる方角（度。北=0, 東=90, 南=180, 西=270）

## 注意

予報はモデルによる推定値です。実際の海の状況は現地で確認し、ローカルルールを守って楽しみましょう。
